An overhead shot of a steaming tonkotsu ramen bowl — glossy chashu, a jammy soft egg, nori and spring onions — shipped as a 1024×1024 JPEG. The program, `main.py`, copies that photograph byte for byte to `entry.png` in the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
